Feature specs for this repository, one folder per change: `specs/<NNN>-<slug>/spec.md`.
Each spec follows the feature-spec template (`templates/sdlc/feature-spec.md`) and each
scenario is built test-first (ADR-0004 — TDD + SDD). Both live in the owner's private
`architecture-docs` repository.
